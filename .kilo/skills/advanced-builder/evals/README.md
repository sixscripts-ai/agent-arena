# Evals - Optional validation cases

Per https://aiquinta.ai/blog/import-agent-skills-from-skill-md-into-developer-agents/

Optional test cases for validation before production.

Use for:
- Input validation scenarios
- Failure modes
- Security checks
- Regression tests
- Expected skill behavior

Each eval should include:
- User request
- Input file
- Expected skill behavior
- Files the agent should access
- Files the agent should not access
- Expected output format
- Failure conditions
